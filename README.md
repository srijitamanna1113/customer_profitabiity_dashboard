# 📊 Customer Profitability Dashboard

## 🔍 Project Overview
This project presents an interactive **Business Performance Dashboard** built using **Streamlit** to analyze sales, profit, and customer behavior.

The goal is to transform raw transactional data into **actionable business insights** for decision-making.

---

## 🚀 Live App
👉 https://srijitamanna1113-customer-profitabiity-dashboard-apptwo-sx6ohy.streamlit.app/

---

## 📂 Dataset
The dataset contains:
- Orders and shipment details  
- Product and division information  
- Sales, cost, and profit metrics  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- Pandas  
- Plotly  

---

## 📊 Key Features

### 📈 Sales & Profit Analysis
- Track total sales and profitability
- Time-series trend analysis

### 🧠 Customer Insights
- Identify top customers
- Analyze revenue concentration

### 💰 Product Profitability
- Top profit-generating products
- Loss-making product detection

### 🎯 Pareto Analysis
- Identify top 20% products driving 80% profit

### 📊 Division Performance
- Compare revenue vs profit across divisions

---

## 🔍 Data Validation
- Profit recalculated using:  
  **Profit = Sales - Cost**
- Ensures realistic and reliable insights

## ⚠️ Business Insights

- Identifies **loss-making products**
- Detects **high customer concentration risk**
- Highlights **top-performing divisions**

## 📄 Research Integration

This dashboard was developed as part of a research project on **business analytics and profitability optimization**.

The study focuses on analyzing transactional data to identify:
- Revenue drivers  
- Profit leakage  
- Customer concentration risk  

The Streamlit dashboard complements the research by providing an **interactive decision-support system**, allowing users to dynamically explore insights such as:
- Product-level profitability  
- Pareto-based contribution analysis  
- Division-wise performance trends  

This integration bridges the gap between **static academic analysis** and **real-time business decision-making tools**.
